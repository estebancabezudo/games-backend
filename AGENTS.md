# Instrucciones específicas de Games

Este repositorio es `games-backend` y su rama permanente es `games`. El repositorio
compartido `cabezudo-dev-backend` se trabaja en el checkout hermano `../platform`,
sobre la misma rama.

Antes de modificar este módulo, leer `docs/agent-memory.md`. Si el cambio afecta
infraestructura compartida, leer también `../platform/docs/agent-memory.md`.
